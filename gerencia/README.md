# GerencIA

App do Home Assistant para o seu dinheiro: caixa do dia a dia (recebimentos, despesas, fixos, parcelas e faturas de cartão), investimentos com rendimento no padrão de mercado, dinheiro de terceiros, fluxo de caixa, projeções e leitura por IA.

Veja a aba **Documentação** do app para instalar e usar.
